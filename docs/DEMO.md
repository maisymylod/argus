# Capturing the demo

A short GIF makes the README land. To record one:

1. Start the stack: `make up`
2. Open http://localhost:8080
3. Pick an AOI (Central Valley or Rondonia), set two dates, and send a query
   such as "show vegetation change and note the sensor revisit time".
4. Watch the map fly to the AOI and the NDVI/change overlay and detection
   polygons animate in, with the grounded answer and citations in the chat.
5. Record the screen (for example with Kap or LICEcap) and save it to
   `docs/demo.gif`, then it renders in the README.

The README references `docs/demo.gif` as a placeholder until recorded.
